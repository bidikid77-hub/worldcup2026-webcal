Cách thêm lịch

  1. iPhone / Apple CalendarBấm “Đăng ký lịch”, chọn Subscribe/Add Calendar. Nếu không tự mở, copy link WebCal.
  2. Google CalendarVào Other calendars → From URL → dán link HTTPS của file ICS.
  3. OutlookVào Add calendar → Subscribe from web → dán link HTTPS.
Lưu ý: Google Calendar và một số ứng dụng có thể cache lịch vài giờ trước khi hiện bản cập nhật mới.
